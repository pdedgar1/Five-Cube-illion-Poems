# Five-Cube-illion Poems

A poetry generator inspired by the 5x5 Rubik's cube.

## How it works

Input the 25 colors from the front face of a 5x5 Rubik's cube using single-letter codes:

- **r** - red
- **o** - orange
- **y** - yellow
- **g** - green
- **b** - blue
- **w** - white

The program will generate a unique poem based on your cube configuration.
